# A1 内容呈现 —— 已实现 / 未实现

对应方案第 3 节 A1。基准提交 `7907d01`。

## 已实现

| 项 | 落地位置 | 说明 |
|---|---|---|
| 安全 Markdown 渲染 | `src/lib/markdown.ts`、`src/components/markdown.tsx` | 段落 / 二三级标题 / 有序无序列表 / 表格 / 链接 / 粗体 / 行内代码 |
| 拒绝危险 HTML | 同上 | 白名单解析，原始 HTML 一律转义为文字；未定义 `dangerouslySetInnerHTML` 直通路径 |
| 链接白名单 | `safeHref()` | 只放行 http(s)、站内相对路径与锚点；拒绝 `javascript:`/`data:`/`vbscript:`/`file:`/`blob:` 与协议相对地址 `//` |
| 一处解析、两处渲染 | `publicationHtml()` 改为复用同一解析器 | 修掉"页面上有表格、发布到第三方却丢失"的分叉 |
| 内容模板 | `src/lib/content-templates.ts` | 是什么 / FAQ / 对比 / 教程，各含必备小节、最少来源数、是否强制表格 |
| 结构校验 | `lintContent()` | 直答过短、缺必备小节、缺表格、来源不足、未绑定事实、占位符未替换、正文含原始 HTML |
| 运营台接入 | `/console/content` | 模板选择 + 骨架预填 + 每篇内容的实时结构检查 |
| 摘要纯文本化 | 知识页 `generateMetadata` | meta description 不再混入 Markdown 标记 |

## 未实现（明确不承诺）

- 不支持引用块、嵌套列表、图片、脚注、表格合并单元格 —— 不支持的语法按纯文本处理，不猜测
- 不支持 HTML 实体解码（`&amp;` 会显示成 `&amp;`）
- 不做内容语义质量评价（是否真的回答了问题仍由人工审核）
- 不做实时预览编辑器（模板骨架直接填进 Markdown 输入框）
